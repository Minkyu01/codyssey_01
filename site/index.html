AI/SW 개발 워크스테이션 구축

컨테이너의 연결 지점을 직접 확인하세요

이 페이지는 커스텀 Docker 이미지에서 제공됩니다. 호스트의 8080 포트는 컨테이너의 80 포트로 연결되고, 데이터 디렉터리는 Docker 볼륨으로 분리할 수 있습니다.

현재 요청 경로 localhost:8080 → container:80

실행 흐름

빌드에서 영속 데이터까지

image → container → service
  1. 01

    이미지 빌드

    Dockerfile과 정적 파일을 변경 불가능한 실행 템플릿으로 묶습니다.

    docker build -t workstation-web:1.0 .
  2. 02

    컨테이너 실행

    이미지에서 격리된 프로세스를 만들고 호스트 포트를 연결합니다.

    docker run -p 8080:80 workstation-web:1.0
  3. 03

    스토리지 분리

    바인드 마운트는 호스트 파일을 반영하고, 볼륨은 데이터를 유지합니다.

    -v workstation-data:/usr/share/nginx/html/data

검증 기준

응답을 받았다면 포트 매핑이 동작합니다

curl http://localhost:8080/healthz의 결과가 ok인지 확인하세요.
